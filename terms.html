1. 서비스

기계중독 통계는 유튜브 채널 “기계중독” 운영자가 본인 채널의 통계를 확인하기 위해 직접 운영하는 개인용 도구입니다. 공개 서비스가 아니며 다른 사용자에게 제공되지 않습니다.

2. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

3. 권한

읽기 전용 권한(youtube.readonly, yt-analytics.readonly)만 사용하며, 채널 콘텐츠나 설정을 변경하지 않습니다.

4. 책임

표시되는 통계는 Google이 제공하는 값을 그대로 정리한 것이며, 집계 지연이나 반올림으로 YouTube 스튜디오의 값과 다를 수 있습니다.
